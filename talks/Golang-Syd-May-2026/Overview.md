# Overview

This presentation describes a program which generates Gleam bindings for Material 3 Expressive (m3e), a modern TypeScript-based Web Component library. The project is driven by the author's wish to leverage robust Material Design 3 UI components within Gleam-based web applications, specifically for personal projects ranging from macro photography and nature research, to genealogical databases and the NP-complete world of multi-league sports scheduling.

# Motivation

Given the _"moved to maintenance mode"_ status of the official Material Web Components, the author identified Material 3 Expressive as a viable successor. To use M3E in the type-safe Gleam / Lustre world, the author developed a toolchain to generate Gleam bindings for the TypeScript source-of-truth.
